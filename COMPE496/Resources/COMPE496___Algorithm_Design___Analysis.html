Module 1: Sorting Algorithms — Part I (1 Hour)

Sorting is the foundation of algorithm study. We begin with three intuitive O(n²) algorithms that illustrate core concepts: comparison, swapping, and incremental construction.

1.1 Bubble Sort

Time: O(n²)Space: O(1)Stable: Yes

How It Works (Verbal Explanation)

  1. Start at the beginning of the array.
  2. Compare each pair of adjacent elements.
  3. If the left element is greater than the right, swap them.
  4. After one full pass, the largest element "bubbles up" to the last position.
  5. Repeat for the remaining unsorted portion (exclude the last sorted elements).
  6. Continue until no swaps are needed in a pass — the array is sorted.

C++ Implementation

#include <iostream>
#include <vector>
using namespace std;

void bubbleSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
                swapped = true;
            }
        }
        if (!swapped) break; // Optimization: early exit
    }
}

int main() {
    vector<int> arr = {64, 34, 25, 12, 22, 11, 90};
    bubbleSort(arr);
    for (int x : arr) cout << x << " ";
    return 0;
}

1.2 Selection Sort

Time: O(n²)Space: O(1)Stable: No

How It Works

  1. Divide the array into a sorted region (left, initially empty) and unsorted region (right).
  2. Find the minimum element in the unsorted region.
  3. Swap it with the first element of the unsorted region.
  4. Expand the sorted region by one element.
  5. Repeat until the entire array is sorted.

C++ Implementation

void selectionSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx])
                minIdx = j;
        }
        swap(arr[i], arr[minIdx]);
    }
}

1.3 Insertion Sort

Time: O(n²) worst, O(n) bestSpace: O(1)Stable: Yes

How It Works

  1. Start from the second element (index 1). Consider the first element as already sorted.
  2. Take the current element as the key.
  3. Compare the key with elements to its left, shifting larger elements one position right.
  4. Insert the key into its correct position in the sorted portion.
  5. Repeat for all remaining elements.
  6. Works like sorting playing cards — you pick one card and insert it in the right place.

C++ Implementation

void insertionSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key;
    }
}

Module 2: Sorting Algorithms — Part II (1 Hour)

These advanced sorting algorithms achieve O(n log n) performance using divide-and-conquer and heap data structures.

2.1 Merge Sort

Time: O(n log n)Space: O(n)Stable: Yes

How It Works

  1. Divide: Split the array into two halves recursively until each sub-array has one element.
  2. Conquer: Each single-element sub-array is trivially sorted.
  3. Merge: Combine two sorted halves by comparing elements from the front of each half and picking the smaller one.
  4. Continue merging until you reconstruct the full sorted array.
  5. Think of it as splitting a deck of cards in half repeatedly, then merging sorted piles back together.

C++ Implementation

void merge(vector<int>& arr, int l, int m, int r) {
    vector<int> L(arr.begin()+l, arr.begin()+m+1);
    vector<int> R(arr.begin()+m+1, arr.begin()+r+1);
    int i = 0, j = 0, k = l;
    while (i < L.size() && j < R.size())
        arr[k++] = (L[i] <= R[j]) ? L[i++] : R[j++];
    while (i < L.size()) arr[k++] = L[i++];
    while (j < R.size()) arr[k++] = R[j++];
}

void mergeSort(vector<int>& arr, int l, int r) {
    if (l < r) {
        int m = l + (r - l) / 2;
        mergeSort(arr, l, m);
        mergeSort(arr, m + 1, r);
        merge(arr, l, m, r);
    }
}

2.2 Quick Sort

Time: O(n log n) avg, O(n²) worstSpace: O(log n)Stable: No

How It Works

  1. Choose a pivot element (commonly the last element).
  2. Partition: Rearrange so elements less than pivot go left, greater go right.
  3. The pivot is now in its final sorted position.
  4. Recursively apply Quick Sort to the left and right sub-arrays.
  5. Base case: sub-arrays of size 0 or 1 are already sorted.
  6. In practice, Quick Sort is often the fastest general-purpose sort due to excellent cache performance.

C++ Implementation

int partition(vector<int>& arr, int low, int high) {
    int pivot = arr[high];
    int i = low - 1;
    for (int j = low; j < high; j++) {
        if (arr[j] < pivot) {
            i++;
            swap(arr[i], arr[j]);
        }
    }
    swap(arr[i + 1], arr[high]);
    return i + 1;
}

void quickSort(vector<int>& arr, int low, int high) {
    if (low < high) {
        int pi = partition(arr, low, high);
        quickSort(arr, low, pi - 1);
        quickSort(arr, pi + 1, high);
    }
}

2.3 Heap Sort

Time: O(n log n)Space: O(1)Stable: No

How It Works

  1. Build a Max-Heap: Rearrange the array so it satisfies the heap property (parent ≥ children).
  2. The largest element is now at the root (index 0).
  3. Extract Max: Swap the root with the last element, reducing heap size by one.
  4. Heapify: Restore the heap property by sifting the new root down.
  5. Repeat extraction until the heap is empty — the array is sorted.
  6. Heap Sort guarantees O(n log n) in all cases, unlike Quick Sort.

C++ Implementation

void heapify(vector<int>& arr, int n, int i) {
    int largest = i;
    int left = 2 * i + 1, right = 2 * i + 2;
    if (left < n && arr[left] > arr[largest]) largest = left;
    if (right < n && arr[right] > arr[largest]) largest = right;
    if (largest != i) {
        swap(arr[i], arr[largest]);
        heapify(arr, n, largest);
    }
}

void heapSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = n / 2 - 1; i >= 0; i--)  // Build heap
        heapify(arr, n, i);
    for (int i = n - 1; i > 0; i--) {      // Extract
        swap(arr[0], arr[i]);
        heapify(arr, i, 0);
    }
}

Module 3: Searching Algorithms (1 Hour)

Searching is one of the most fundamental operations. We cover two essential approaches: brute-force linear scan and the elegant binary search.

3.1 Linear Search

Time: O(n)Space: O(1)

How It Works

  1. Start from the first element of the array.
  2. Compare the current element with the target value.
  3. If they match, return the current index — found!
  4. If not, move to the next element.
  5. If you reach the end without finding the target, return -1 — not found.
  6. This is the simplest search. It works on unsorted data but is slow for large datasets.

C++ Implementation

int linearSearch(const vector<int>& arr, int target) {
    for (int i = 0; i < arr.size(); i++) {
        if (arr[i] == target)
            return i;  // Found at index i
    }
    return -1;  // Not found
}

3.2 Binary Search

Time: O(log n)Space: O(1)Requires: Sorted Array

How It Works

  1. The array must be sorted before applying binary search.
  2. Set two pointers: low = 0 and high = n-1.
  3. Calculate the middle index: mid = low + (high - low) / 2.
  4. If arr[mid] == target, you found it!
  5. If arr[mid] < target, search the right half: low = mid + 1.
  6. If arr[mid] > target, search the left half: high = mid - 1.
  7. Repeat until low > high (not found) or you find the target.
  8. Each step eliminates half the remaining elements — incredibly efficient!

C++ Implementation

int binarySearch(const vector<int>& arr, int target) {
    int low = 0, high = arr.size() - 1;
    while (low <= high) {
        int mid = low + (high - low) / 2;
        if (arr[mid] == target)
            return mid;
        else if (arr[mid] < target)
            low = mid + 1;
        else
            high = mid - 1;
    }
    return -1;  // Not found
}

Module 4: Graph Algorithms (1 Hour)

Graphs model relationships — social networks, maps, dependencies. These three algorithms are indispensable tools for traversing and analyzing graphs.

4.1 Breadth-First Search (BFS)

Time: O(V + E)Space: O(V)

How It Works

  1. Start at a source node. Mark it as visited and add it to a queue.
  2. Dequeue a node, process it, and enqueue all its unvisited neighbors.
  3. Mark each neighbor as visited when enqueuing to avoid revisiting.
  4. Repeat until the queue is empty.
  5. BFS explores nodes level by level — all nodes at distance 1 first, then distance 2, etc.
  6. This guarantees the shortest path in unweighted graphs.

C++ Implementation

#include <queue>
void bfs(vector<vector<int>>& adj, int start) {
    int n = adj.size();
    vector<bool> visited(n, false);
    queue<int> q;
    visited[start] = true;
    q.push(start);
    while (!q.empty()) {
        int node = q.front(); q.pop();
        cout << node << " ";
        for (int neighbor : adj[node]) {
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                q.push(neighbor);
            }
        }
    }
}

4.2 Depth-First Search (DFS)

Time: O(V + E)Space: O(V)

How It Works

  1. Start at a source node. Mark it as visited.
  2. Explore one unvisited neighbor, then recursively explore from that neighbor.
  3. Go as deep as possible along each branch before backtracking.
  4. When stuck (no unvisited neighbors), backtrack to the previous node.
  5. Continue until all reachable nodes are visited.
  6. Uses a stack (implicit via recursion, or explicit). Great for maze solving and topological sorting.

C++ Implementation

void dfs(vector<vector<int>>& adj, int node, vector<bool>& visited) {
    visited[node] = true;
    cout << node << " ";
    for (int neighbor : adj[node]) {
        if (!visited[neighbor])
            dfs(adj, neighbor, visited);
    }
}
// Iterative version using explicit stack:
void dfsIterative(vector<vector<int>>& adj, int start) {
    int n = adj.size();
    vector<bool> visited(n, false);
    stack<int> s;
    s.push(start);
    while (!s.empty()) {
        int node = s.top(); s.pop();
        if (visited[node]) continue;
        visited[node] = true;
        cout << node << " ";
        for (int i = adj[node].size()-1; i >= 0; i--)
            if (!visited[adj[node][i]])
                s.push(adj[node][i]);
    }
}

4.3 Dijkstra's Shortest Path

Time: O((V+E) log V)Space: O(V)Requires: Non-negative weights

How It Works

  1. Initialize distance to source as 0, all others as infinity (∞).
  2. Use a min-priority queue. Insert (0, source).
  3. Extract the node with smallest distance from the queue.
  4. For each neighbor, calculate new_dist = dist[current] + edge_weight.
  5. If new_dist < dist[neighbor], update and insert neighbor into the queue.
  6. Repeat until the queue is empty. Each node is finalized once.
  7. This is the gold standard for single-source shortest paths in weighted graphs.

C++ Implementation

#include <climits>
typedef pair<int,int> pii;
vector<int> dijkstra(vector<vector<pii>>& adj, int src) {
    int n = adj.size();
    vector<int> dist(n, INT_MAX);
    priority_queue<pii, vector<pii>, greater<pii>> pq;
    dist[src] = 0;
    pq.push({0, src});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist[u]) continue;
        for (auto [v, w] : adj[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
    return dist;
}

Module 5: Dynamic Programming (1 Hour)

Dynamic Programming (DP) solves complex problems by breaking them into overlapping subproblems and storing results to avoid redundant computation. It is the most powerful algorithmic technique for optimization problems.

5.1 Fibonacci Sequence (DP Introduction)

Naive: O(2ⁿ)DP: O(n)Space: O(n) or O(1)

How It Works

  1. Fibonacci: F(0)=0, F(1)=1, F(n) = F(n-1) + F(n-2).
  2. Naive recursion recalculates the same values exponentially many times.
  3. Memoization (Top-Down): Store computed results in a table. Before computing F(n), check if it's already cached.
  4. Tabulation (Bottom-Up): Fill a table from F(0) up to F(n), each entry using the two before it.
  5. This simple example perfectly illustrates the DP principle: overlapping subproblems + optimal substructure.

C++ Implementation

// Bottom-Up DP (Tabulation)
long long fibonacci(int n) {
    if (n <= 1) return n;
    vector<long long> dp(n + 1);
    dp[0] = 0; dp[1] = 1;
    for (int i = 2; i <= n; i++)
        dp[i] = dp[i-1] + dp[i-2];
    return dp[n];
}
// Space-Optimized O(1)
long long fibOptimized(int n) {
    if (n <= 1) return n;
    long long prev2 = 0, prev1 = 1, curr;
    for (int i = 2; i <= n; i++) {
        curr = prev1 + prev2;
        prev2 = prev1;
        prev1 = curr;
    }
    return prev1;
}

5.2 Longest Common Subsequence (LCS)

Time: O(m × n)Space: O(m × n)

How It Works

  1. Given two strings X and Y, find the longest subsequence common to both.
  2. Create a 2D table dp[i][j] = length of LCS of X[0..i-1] and Y[0..j-1].
  3. If X[i-1] == Y[j-1]: characters match, so dp[i][j] = dp[i-1][j-1] + 1.
  4. Otherwise: dp[i][j] = max(dp[i-1][j], dp[i][j-1]) — skip one character from either string.
  5. Fill the table row by row. The answer is in dp[m][n].
  6. To reconstruct the actual LCS, trace back from dp[m][n] following the choices made.

C++ Implementation

string lcs(const string& X, const string& Y) {
    int m = X.size(), n = Y.size();
    vector<vector<int>> dp(m+1, vector<int>(n+1, 0));
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            dp[i][j] = (X[i-1] == Y[j-1])
                ? dp[i-1][j-1] + 1
                : max(dp[i-1][j], dp[i][j-1]);
    // Reconstruct
    string result;
    int i = m, j = n;
    while (i > 0 && j > 0) {
        if (X[i-1] == Y[j-1]) {
            result = X[i-1] + result;
            i--; j--;
        } else if (dp[i-1][j] > dp[i][j-1]) i--;
        else j--;
    }
    return result;
}

5.3 0/1 Knapsack Problem

Time: O(n × W)Space: O(n × W)

How It Works

  1. Given n items with weights and values, and a knapsack of capacity W.
  2. Goal: maximize total value without exceeding capacity. Each item is taken or not (0/1).
  3. Create table dp[i][w] = max value using first i items with capacity w.
  4. For each item i and capacity w: either skip it (dp[i-1][w]) or take it (dp[i-1][w - weight[i]] + value[i]).
  5. Choose the option giving higher value: dp[i][w] = max(skip, take).
  6. Answer is dp[n][W]. Trace back to find which items were selected.

C++ Implementation

int knapsack(int W, vector<int>& wt, vector<int>& val) {
    int n = wt.size();
    vector<vector<int>> dp(n+1, vector<int>(W+1, 0));
    for (int i = 1; i <= n; i++) {
        for (int w = 0; w <= W; w++) {
            dp[i][w] = dp[i-1][w]; // skip item i
            if (wt[i-1] <= w)
                dp[i][w] = max(dp[i][w],
                    dp[i-1][w - wt[i-1]] + val[i-1]);
        }
    }
    return dp[n][W];
}

Module 6: Tree Algorithms & Greedy Strategies (1 Hour)

Trees are hierarchical structures fundamental to CS. Greedy algorithms build solutions by making locally optimal choices. We cover BST traversals and Kruskal's MST algorithm.

6.1 Binary Search Tree Traversals

Time: O(n)Space: O(h) where h = tree height

How It Works

  1. A BST maintains the property: left child < parent < right child.
  2. In-Order (Left → Root → Right): Visits nodes in ascending sorted order. This is the most useful BST traversal.
  3. Pre-Order (Root → Left → Right): Visits the root first. Useful for copying/serializing the tree.
  4. Post-Order (Left → Right → Root): Visits root last. Useful for deleting the tree or evaluating expressions.
  5. Level-Order (BFS): Visits nodes level by level using a queue — same as BFS on trees.
  6. All traversals visit every node exactly once, giving O(n) time complexity.

C++ Implementation

struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode(int v) : val(v), left(nullptr), right(nullptr) {}
};

void inOrder(TreeNode* root) {
    if (!root) return;
    inOrder(root->left);
    cout << root->val << " ";
    inOrder(root->right);
}

void preOrder(TreeNode* root) {
    if (!root) return;
    cout << root->val << " ";
    preOrder(root->left);
    preOrder(root->right);
}

void postOrder(TreeNode* root) {
    if (!root) return;
    postOrder(root->left);
    postOrder(root->right);
    cout << root->val << " ";
}

// BST Insert
TreeNode* insert(TreeNode* root, int val) {
    if (!root) return new TreeNode(val);
    if (val < root->val) root->left = insert(root->left, val);
    else root->right = insert(root->right, val);
    return root;
}

6.2 Kruskal's Minimum Spanning Tree

Time: O(E log E)Space: O(V)Greedy Algorithm

How It Works

  1. A Minimum Spanning Tree connects all vertices with minimum total edge weight and no cycles.
  2. Sort all edges by weight in ascending order.
  3. Initialize a Union-Find (Disjoint Set) structure with each vertex in its own set.
  4. Iterate through sorted edges. For each edge (u, v):
  5. If u and v are in different sets, add this edge to the MST and union their sets.
  6. If they're in the same set, skip (adding it would create a cycle).
  7. Stop when you have V-1 edges — the MST is complete.
  8. This greedy choice (always pick cheapest safe edge) is provably optimal.

C++ Implementation

struct Edge { int u, v, w; };

class UnionFind {
    vector<int> parent, rank_;
public:
    UnionFind(int n) : parent(n), rank_(n, 0) {
        iota(parent.begin(), parent.end(), 0);
    }
    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }
    bool unite(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return false;
        if (rank_[px] < rank_[py]) swap(px, py);
        parent[py] = px;
        if (rank_[px] == rank_[py]) rank_[px]++;
        return true;
    }
};

vector<Edge> kruskal(int V, vector<Edge>& edges) {
    sort(edges.begin(), edges.end(),
         [](const Edge& a, const Edge& b){ return a.w < b.w; });
    UnionFind uf(V);
    vector<Edge> mst;
    for (auto& e : edges) {
        if (uf.unite(e.u, e.v))
            mst.push_back(e);
        if (mst.size() == V - 1) break;
    }
    return mst;
}
