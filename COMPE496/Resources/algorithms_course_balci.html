Foundations & Complexity Analysis

Before writing a single algorithm, we need the mathematical vocabulary to reason about efficiency. This module covers asymptotic notation, algorithm classification, and the Master Theorem.

⏱ 60 MINUTES · LECTURE + DISCUSSION

1.1 Asymptotic Notation

Asymptotic notation lets us express how an algorithm's resource usage (time or memory) grows relative to the size of its input n. We ignore constant factors and low-order terms—we care about the shape of growth.

Big-O (Upper Bound)

O(g(n)) means the algorithm's running time grows no faster than g(n). It is a worst-case promise. If we say Bubble Sort is O(n²), we guarantee it won't take longer than some constant multiple of n² for any input.

Big-Omega (Lower Bound)

Ω(g(n)) means the algorithm takes at least g(n) time. It describes best-case behavior. Any comparison-based sorting algorithm requires Ω(n log n) comparisons—this is provably optimal.

Big-Theta (Tight Bound)

Θ(g(n)) means both upper and lower bounds are the same. Merge Sort is Θ(n log n)—it always takes that long, best, worst, and average case.

1.3 Recurrence Relations & Master Theorem

Divide-and-conquer algorithms naturally produce recurrences. The Master Theorem solves them in three cases for the form T(n) = aT(n/b) + f(n):

  • Case 1: f(n) = O(n^(log_b a − ε)) → T(n) = Θ(n^(log_b a))
  • Case 2: f(n) = Θ(n^(log_b a)) → T(n) = Θ(n^(log_b a) · log n)
  • Case 3: f(n) = Ω(n^(log_b a + ε)) → T(n) = Θ(f(n))

Merge Sort Example: T(n) = 2T(n/2) + O(n). Here a=2, b=2, log₂2=1. f(n)=O(n)=Θ(n¹) → Case 2 → T(n) = Θ(n log n).

2.1 Bubble Sort

Bubble Sort repeatedly walks through the array, comparing adjacent elements and swapping them if out of order. The largest unsorted element "bubbles up" to its correct position on each pass. Simple to understand but inefficient—used mainly for teaching purposes.

Algorithm Steps
01Set a flag swapped = true to enter the outer loop.
02For each pass through the array (from index 0 to n−1−pass), compare arr[j] and arr[j+1].
03If arr[j] > arr[j+1], swap them and set swapped = true.
04If no swap occurred in a full pass, the array is already sorted — exit early (optimization).
05Repeat until all passes complete. The last i elements are always in their final position.

C++ 17Bubble Sort — Optimized
void bubbleSort(std::vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        // Last i elements are already in place
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                std::swap(arr[j], arr[j + 1]);
                swapped = true;
            }
        }
        // Early exit: array already sorted
        if (!swapped) break;
    }
}

2.2 Selection Sort

Selection Sort divides the array into a sorted left portion and an unsorted right portion. On each pass, it finds the minimum element in the unsorted portion and swaps it into its correct position. It always performs exactly n(n−1)/2 comparisons regardless of input—no early exit possible.

Algorithm Steps
01Begin with the entire array unsorted. Set the boundary at index i = 0.
02Scan the unsorted portion (i to n−1) to find the index of the minimum element.
03Swap the minimum element with arr[i], extending the sorted portion by one.
04Advance i by 1 and repeat until i = n−1. The array is now fully sorted.
C++ 17Selection Sort
void selectionSort(std::vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        // Find minimum in unsorted portion
        for (int j = i + 1; j < n; j++)
            if (arr[j] < arr[minIdx]) minIdx = j;
        // Move minimum to its final position
        if (minIdx != i)
            std::swap(arr[i], arr[minIdx]);
    }
}

2.3 Insertion Sort

Insertion Sort builds a sorted array one element at a time—much like sorting a hand of playing cards. It's efficient for small data sets and nearly-sorted arrays (O(n) best case). It's also online: it can sort as it receives data.

Algorithm Steps
01Start from index i = 1. The subarray arr[0..0] is trivially sorted.
02Store arr[i] as the "key". This is the card you are about to insert.
03Shift all sorted elements greater than the key one position to the right.
04Insert the key into the gap. Now arr[0..i] is sorted.
05Increment i and repeat until i = n−1.
C++ 17Insertion Sort
void insertionSort(std::vector<int>& arr) {
    int n = arr.size();
    for (int i = 1; i < n; i++) {
        int key = arr[i];
        int j = i - 1;
        // Shift elements greater than key to the right
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = key; // Insert key at correct position
    }
}

2.4 Merge Sort

Merge Sort is a classic Divide and Conquer algorithm with guaranteed O(n log n) in all cases. It recursively splits the array in half, sorts each half, then merges them. The merge step is linear—combining two sorted arrays requires one pass. It requires O(n) auxiliary space for the merge operation.

Algorithm Steps
01Divide: Find the midpoint mid = (left + right) / 2. Split into left half [left..mid] and right half [mid+1..right].
02Conquer: Recursively call mergeSort on both halves. The base case is a single element (left ≥ right), which is trivially sorted.
03Merge: Use two pointers i and j into the left and right halves. Compare arr[i] and arr[j], copy the smaller into a temporary buffer, advance that pointer.
04Copy any remaining elements from either half into the buffer.
05Copy the buffer back into arr[left..right]. This subarray is now fully sorted.

C++ 17Merge Sort — Recursive
void merge(std::vector<int>& arr, int l, int m, int r) {
    std::vector<int> left(arr.begin() + l, arr.begin() + m + 1);
    std::vector<int> right(arr.begin() + m + 1, arr.begin() + r + 1);
    int i = 0, j = 0, k = l;
    while (i < left.size() && j < right.size())
        arr[k++] = (left[i] <= right[j]) ? left[i++] : right[j++];
    while (i < left.size())  arr[k++] = left[i++];
    while (j < right.size()) arr[k++] = right[j++];
}

void mergeSort(std::vector<int>& arr, int l, int r) {
    if (l >= r) return; // Base case: single element
    int m = l + (r - l) / 2; // Avoids integer overflow vs (l+r)/2
    mergeSort(arr, l, m);
    mergeSort(arr, m + 1, r);
    merge(arr, l, m, r);
}

2.5 Quick Sort

Quick Sort is the most widely used sorting algorithm in practice. It works by selecting a pivot element and partitioning the array so all elements smaller than the pivot are to its left, and all larger elements are to its right. The pivot is then in its final sorted position. Recursively apply to both partitions.

Algorithm Steps
01Choose pivot: Common strategies include last element, first element, median-of-three, or random. Pivot selection dramatically affects performance.
02Partition (Lomuto scheme): Use pointer i = low−1. Walk j from low to high−1. Whenever arr[j] ≤ pivot, increment i and swap arr[i] with arr[j].
03After the loop, place the pivot at position i+1 by swapping arr[i+1] with arr[high]. Return i+1 as the pivot index.
04Recurse: Apply quickSort to the sub-array left of pivot [low..pivotIdx−1] and right of pivot [pivotIdx+1..high].
05Base case: When low ≥ high, the sub-array has 0 or 1 elements and is trivially sorted.
⚠ Worst Case: Quick Sort degrades to O(n²) when the pivot is always the minimum or maximum (e.g., a sorted array with last-element pivot). Always use randomized pivot or median-of-three in production.
C++ 17Quick Sort — Lomuto Partition
int partition(std::vector<int>& arr, int low, int high) {
    // Randomized pivot to avoid worst-case O(n²)
    int randIdx = low + rand() % (high - low + 1);
    std::swap(arr[randIdx], arr[high]);
    int pivot = arr[high];
    int i = low - 1;
    for (int j = low; j < high; j++) {
        if (arr[j] <= pivot)
            std::swap(arr[++i], arr[j]);
    }
    std::swap(arr[i + 1], arr[high]);
    return i + 1;
}

void quickSort(std::vector<int>& arr, int low, int high) {
    if (low < high) {
        int pi = partition(arr, low, high);
        quickSort(arr, low, pi - 1);
        quickSort(arr, pi + 1, high);
    }
}

2.6 Heap Sort

Heap Sort exploits the binary heap data structure. It first builds a max-heap from the input array, then repeatedly extracts the maximum element (the root) and places it at the end. It combines the best traits of Merge Sort (O(n log n) worst case) and Selection Sort (O(1) space).

Algorithm Steps
01Build Max-Heap: Call heapify on all non-leaf nodes from index n/2−1 down to 0. After this, arr[0] is the maximum element.
02Swap the root (maximum) with the last element arr[n−1]. The maximum is now at its final sorted position.
03Reduce the heap size by 1, and heapify down from the root to restore the max-heap property.
04Repeat steps 2−3 for all remaining elements. Each iteration places one more element in sorted order.
C++ 17Heap Sort
void heapify(std::vector<int>& arr, int n, int i) {
    int largest = i;
    int left  = 2 * i + 1;
    int right = 2 * i + 2;
    if (left  < n && arr[left]  > arr[largest]) largest = left;
    if (right < n && arr[right] > arr[largest]) largest = right;
    if (largest != i) {
        std::swap(arr[i], arr[largest]);
        heapify(arr, n, largest); // Recursively fix the sub-tree
    }
}

void heapSort(std::vector<int>& arr) {
    int n = arr.size();
    // Phase 1: Build max-heap (start from last non-leaf)
    for (int i = n / 2 - 1; i >= 0; i--)
        heapify(arr, n, i);
    // Phase 2: Extract elements from heap one by one
    for (int i = n - 1; i > 0; i--) {
        std::swap(arr[0], arr[i]); // Move current max to end
        heapify(arr, i, 0);         // Heapify reduced heap
    }
}

Searching & Graph Traversal

Searching is about finding structure in data. We cover array searching, then BFS and DFS—the two foundational graph traversal patterns that underpin dozens of other algorithms.

⏱ 60 MINUTES · FOUR ALGORITHMS

3.1 Linear Search

Linear Search inspects each element sequentially until the target is found or the array is exhausted. It works on unsorted and sorted arrays alike, requires no pre-processing, but is slow on large data.

Algorithm Steps
01Start at index i = 0.
02Compare arr[i] with target. If equal, return i (found).
03Increment i. If i < n, go to step 2.
04If the loop ends without a match, return −1 (not found).
C++ 17Linear Search
int linearSearch(const std::vector<int>& arr, int target) {
    for (int i = 0; i < arr.size(); i++)
        if (arr[i] == target) return i;
    return -1; // Not found
}
// Time: O(n) | Space: O(1)

3.2 Binary Search

Binary Search requires a sorted array and achieves O(log n) by halving the search space on each step. For 1 billion elements, Binary Search takes at most 30 comparisons. Linear Search would take up to 1 billion.

Algorithm Steps
01Set low = 0, high = n−1. These define the active search interval.
02Compute mid = low + (high−low)/2 (avoids integer overflow).
03If arr[mid] == target, return mid.
04If arr[mid] < target, the target must be in the right half. Set low = mid + 1.
05If arr[mid] > target, the target must be in the left half. Set high = mid − 1.
06Repeat from step 2. If low > high, the target is not in the array; return −1.

C++ 17Binary Search — Iterative & Recursive
// Iterative version — preferred (no stack overhead)
int binarySearch(const std::vector<int>& arr, int target) {
    int low = 0, high = arr.size() - 1;
    while (low <= high) {
        int mid = low + (high - low) / 2;
        if      (arr[mid] == target) return mid;
        else if (arr[mid] < target)  low = mid + 1;
        else                          high = mid - 1;
    }
    return -1;
}

// Recursive version
int binarySearchR(const std::vector<int>& arr, int target, int low, int high) {
    if (low > high) return -1;
    int mid = low + (high - low) / 2;
    if (arr[mid] == target) return mid;
    if (arr[mid] < target)  return binarySearchR(arr, target, mid + 1, high);
    return binarySearchR(arr, target, low, mid - 1);
}
// Time: O(log n) | Space: O(1) iterative, O(log n) recursive

3.3 Breadth-First Search (BFS)

BFS explores a graph level by level using a queue. It discovers all nodes at distance k before any node at distance k+1. This property makes BFS the right choice for shortest path in unweighted graphs, and for level-order tree traversal.

Algorithm Steps
01Enqueue the start node. Mark it as visited in a boolean array to avoid re-processing cycles.
02While the queue is not empty: dequeue the front node, process it (print, check for target, etc.).
03For each unvisited neighbor of the current node: mark as visited and enqueue it.
04Repeat until the queue empties. Every reachable node has been visited exactly once.

C++ 17BFS — Adjacency List Representation
#include <queue>
#include <vector>

void bfs(const std::vector<std::vector<int>>& adj, int start) {
    int n = adj.size();
    std::vector<bool> visited(n, false);
    std::queue<int> q;

    visited[start] = true;
    q.push(start);

    while (!q.empty()) {
        int node = q.front(); q.pop();
        std::cout << node << " ";

        for (int neighbor : adj[node]) {
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                q.push(neighbor);
            }
        }
    }
}
// Time: O(V + E) | Space: O(V)

3.4 Depth-First Search (DFS)

DFS explores as far as possible along each branch before backtracking. It uses a stack (either explicit or the call stack via recursion). DFS is the foundation of topological sort, cycle detection, connected components, and maze solving.

Algorithm Steps (Recursive)
01Mark the current node as visited and process it.
02For each unvisited neighbor of the current node: recursively call DFS on that neighbor.
03When no unvisited neighbors remain, return (backtrack to the previous call).
04After all recursive calls from the start node return, all reachable nodes have been visited.
C++ 17DFS — Recursive & Iterative
// Recursive DFS (elegant, uses call stack)
void dfsRecursive(const std::vector<std::vector<int>>& adj,
                   std::vector<bool>& visited, int node) {
    visited[node] = true;
    std::cout << node << " ";
    for (int neighbor : adj[node])
        if (!visited[neighbor])
            dfsRecursive(adj, visited, neighbor);
}

// Iterative DFS (explicit stack, avoids stack overflow)
void dfsIterative(const std::vector<std::vector<int>>& adj, int start) {
    int n = adj.size();
    std::vector<bool> visited(n, false);
    std::stack<int> stk;
    stk.push(start);
    while (!stk.empty()) {
        int node = stk.top(); stk.pop();
        if (visited[node]) continue;
        visited[node] = true;
        std::cout << node << " ";
        for (int neighbor : adj[node])
            if (!visited[neighbor]) stk.push(neighbor);
    }
}
// Time: O(V + E) | Space: O(V)
BFS vs DFS: Use BFS for shortest path (unweighted) and level-order. Use DFS for topological sort, connected components, cycle detection, and pathfinding in mazes. BFS uses more memory (queue can hold O(V) nodes); DFS uses O(depth) space.

4.1 Dijkstra's Shortest Path Algorithm

Dijkstra's algorithm finds the shortest path from a source to all other nodes in a weighted graph with non-negative edge weights. It is a greedy algorithm—at each step it picks the unvisited node with the minimum known distance.

Algorithm Steps
01Initialize dist[source] = 0 and dist[all others] = ∞. Add source to a min-priority queue.
02Extract the node u with the smallest tentative distance from the queue.
03For each neighbor v of u with edge weight w: if dist[u] + w < dist[v], update dist[v] = dist[u] + w and enqueue v with its new distance.
04Mark u as processed — we have the definitive shortest path to u.
05Repeat until the priority queue is empty. All reachable nodes have optimal distances.

C++ 17Dijkstra's Algorithm — Min-Heap Priority Queue
#include <queue>
#include <climits>

using pii = std::pair<int,int>; // {distance, node}

std::vector<int> dijkstra(
    const std::vector<std::vector<pii>>& adj, // adj[u] = {weight, v}
    int src)
{
    int n = adj.size();
    std::vector<int> dist(n, INT_MAX);
    std::priority_queue<pii, std::vector<pii>, std::greater<pii>> pq;

    dist[src] = 0;
    pq.push({0, src});

    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist[u]) continue; // Stale entry

        for (auto [w, v] : adj[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
    return dist;
}
// Time: O((V + E) log V) | Space: O(V + E)

4.2 Bellman-Ford Algorithm

Bellman-Ford handles negative edge weights—something Dijkstra cannot do. It also detects negative-weight cycles (useful in finance for arbitrage detection). It is slower than Dijkstra but more general.

Algorithm Steps
01Initialize dist[source] = 0, dist[all others] = ∞.
02Repeat V−1 times (V = number of vertices): for every edge (u, v, w), if dist[u] + w < dist[v], relax: dist[v] = dist[u] + w.
03After V−1 relaxations, all shortest paths are found (shortest path can have at most V−1 edges).
04Negative cycle check: Do one more pass. If any distance can still be reduced, a negative cycle is present — report it.
C++ 17Bellman-Ford Algorithm
struct Edge { int u, v, w; };

std::vector<int> bellmanFord(int V, const std::vector<Edge>& edges, int src) {
    std::vector<int> dist(V, INT_MAX);
    dist[src] = 0;

    // Relax all edges V-1 times
    for (int i = 0; i < V - 1; i++)
        for (const auto& e : edges)
            if (dist[e.u] != INT_MAX && dist[e.u] + e.w < dist[e.v])
                dist[e.v] = dist[e.u] + e.w;

    // Detect negative weight cycle
    for (const auto& e : edges)
        if (dist[e.u] != INT_MAX && dist[e.u] + e.w < dist[e.v])
            throw std::runtime_error("Negative cycle detected");

    return dist;
}
// Time: O(V·E) | Space: O(V)

4.3 Floyd-Warshall (All-Pairs Shortest Path)

Floyd-Warshall finds shortest paths between all pairs of vertices in a single O(V³) run. It uses dynamic programming—for each intermediate node k, it asks: "Is the path from i to j shorter by going through k?"

Algorithm Steps
01Initialize a V×V distance matrix: dist[i][i] = 0; dist[i][j] = edge weight if (i,j) is an edge; else ∞.
02For each intermediate node k from 0 to V−1:
03   For each pair (i, j): if dist[i][k] + dist[k][j] < dist[i][j], update dist[i][j].
04After all V iterations, dist[i][j] holds the shortest path between every pair (i, j).
C++ 17Floyd-Warshall Algorithm
void floydWarshall(std::vector<std::vector<int>>& dist) {
    int V = dist.size();
    for (int k = 0; k < V; k++)
        for (int i = 0; i < V; i++)
            for (int j = 0; j < V; j++)
                if (dist[i][k] != INT_MAX && dist[k][j] != INT_MAX)
                    dist[i][j] = std::min(dist[i][j], dist[i][k] + dist[k][j]);
    // Negative cycle: dist[i][i] < 0 for some i
}
// Time: O(V³) | Space: O(V²)

4.4 Minimum Spanning Tree — Kruskal's Algorithm

A Minimum Spanning Tree (MST) connects all vertices with the minimum total edge weight, using no cycles. Kruskal's is greedy: sort all edges by weight, then greedily add edges as long as they don't form a cycle (checked using a Union-Find / Disjoint Set Union data structure).

Algorithm Steps
01Sort all edges in non-decreasing order of weight.
02Initialize a Union-Find (DSU) structure where every node is its own component.
03For each edge (u, v, w) in sorted order: if u and v are in different components (find(u) ≠ find(v)), add the edge to the MST and union their components.
04Stop when the MST has V−1 edges (a spanning tree of V nodes always has exactly V−1 edges).
C++ 17Kruskal's MST — With Union-Find
struct DSU {
    std::vector<int> parent, rank;
    DSU(int n) : parent(n), rank(n, 0) { std::iota(parent.begin(), parent.end(), 0); }
    int find(int x) { return parent[x] == x ? x : parent[x] = find(parent[x]); }
    bool unite(int x, int y) {
        x = find(x); y = find(y);
        if (x == y) return false;
        if (rank[x] < rank[y]) std::swap(x, y);
        parent[y] = x;
        if (rank[x] == rank[y]) rank[x]++;
        return true;
    }
};

int kruskal(int V, std::vector<std::tuple<int,int,int>> edges) {
    std::sort(edges.begin(), edges.end()); // Sort by weight (first element)
    DSU dsu(V);
    int mstWeight = 0, edgesUsed = 0;
    for (auto [w, u, v] : edges) {
        if (dsu.unite(u, v)) {
            mstWeight += w;
            if (++edgesUsed == V - 1) break;
        }
    }
    return mstWeight;
}
// Time: O(E log E) | Space: O(V)

4.5 Prim's MST Algorithm

Prim's grows the MST from a starting vertex, at each step adding the minimum-weight edge that connects the MST to a vertex outside it. It is more efficient on dense graphs (O(E log V) with a priority queue) compared to Kruskal's.

C++ 17Prim's Algorithm — Priority Queue
int prim(const std::vector<std::vector<pii>>& adj, int src) {
    int n = adj.size();
    std::vector<bool> inMST(n, false);
    std::vector<int> key(n, INT_MAX);
    std::priority_queue<pii, std::vector<pii>, std::greater<pii>> pq;

    key[src] = 0;
    pq.push({0, src});
    int mstWeight = 0;

    while (!pq.empty()) {
        auto [w, u] = pq.top(); pq.pop();
        if (inMST[u]) continue;
        inMST[u] = true;
        mstWeight += w;
        for (auto [ew, v] : adj[u])
            if (!inMST[v] && ew < key[v]) {
                key[v] = ew;
                pq.push({ew, v});
            }
    }
    return mstWeight;
}
// Time: O((V + E) log V) | Space: O(V)

Dynamic Programming

Dynamic programming solves complex problems by breaking them into simpler overlapping sub-problems and storing results to avoid redundant computation. It is arguably the most powerful technique in competitive programming.

⏱ 60 MINUTES · FOUR PROBLEMS
Two conditions for DP: (1) Optimal Substructure—the optimal solution contains optimal solutions to sub-problems. (2) Overlapping Sub-problems—the same sub-problems are solved repeatedly.
Top-Down (Memoization) = recursion + cache. Write it naturally with recursion, add a memo table. Bottom-Up (Tabulation) = build from smallest sub-problems up. Avoids recursion overhead and stack overflow.

5.1 Fibonacci — DP Introduction

The Fibonacci sequence perfectly illustrates why DP matters. Naive recursion recomputes fib(2), fib(3), fib(4)... exponentially many times. Memoization or tabulation reduces this to O(n).

Naive Recursion → DP Transformation
NAIVEfib(n) = fib(n−1) + fib(n−2). Time: O(2ⁿ). Computes fib(30) with over 1 billion calls.
MEMOAdd a cache map. Before computing, check if result already known. Time: O(n), Space: O(n).
TABLEBuild table bottom-up: dp[0]=0, dp[1]=1, dp[i]=dp[i-1]+dp[i-2]. Time: O(n), Space: O(1) with two variables.
C++ 17Fibonacci — Three Implementations
// O(2ⁿ) — Naive recursion (DO NOT USE for large n)
long long fibNaive(int n) {
    return n <= 1 ? n : fibNaive(n-1) + fibNaive(n-2);
}

// O(n) — Top-Down Memoization
std::unordered_map<int, long long> memo;
long long fibMemo(int n) {
    if (n <= 1) return n;
    if (memo.count(n)) return memo[n];
    return memo[n] = fibMemo(n-1) + fibMemo(n-2);
}

// O(n) time, O(1) space — Bottom-Up Tabulation
long long fibDP(int n) {
    if (n <= 1) return n;
    long long prev2 = 0, prev1 = 1;
    for (int i = 2; i <= n; i++) {
        long long curr = prev1 + prev2;
        prev2 = prev1;
        prev1 = curr;
    }
    return prev1;
}

5.2 The 0/1 Knapsack Problem

Given n items each with a weight and value, and a knapsack of capacity W: maximize the total value while keeping total weight ≤ W. Each item can be taken (1) or left (0)—no fractions. This is a fundamental NP-hard problem solved in pseudo-polynomial time with DP.

DP Formulation
STATEdp[i][w] = maximum value using the first i items with weight capacity w.
BASEdp[0][w] = 0 for all w (no items → no value). dp[i][0] = 0 for all i (zero capacity → no items).
CHOICEFor each item i, either skip it: dp[i][w] = dp[i−1][w], or take it (if weight[i] ≤ w): dp[i][w] = dp[i−1][w−weight[i]] + value[i].
RECUR.dp[i][w] = max(dp[i−1][w], dp[i−1][w−wt[i]] + val[i]) if wt[i] ≤ w.
ANSWERdp[n][W] is the optimal value. Trace back through the table to find which items were selected.
C++ 170/1 Knapsack — Bottom-Up DP
int knapsack(int W,
             const std::vector<int>& wt,
             const std::vector<int>& val) {
    int n = wt.size();
    // dp[w] = max value with capacity w (1D space-optimized)
    std::vector<int> dp(W + 1, 0);

    for (int i = 0; i < n; i++)
        // Traverse right-to-left to avoid using item i twice
        for (int w = W; w >= wt[i]; w--)
            dp[w] = std::max(dp[w], dp[w - wt[i]] + val[i]);

    return dp[W];
}
// Time: O(n·W) | Space: O(W) — space-optimized

// Usage example:
// wt = {2, 3, 4, 5}, val = {3, 4, 5, 6}, W = 8
// knapsack(8, wt, val) → 10  (items 0+3: wt=7, val=9... or items 1+2: wt=7, val=9)

5.3 Longest Common Subsequence (LCS)

LCS finds the longest sequence of characters common to two strings (not necessarily contiguous). It underlies diff tools (git diff), bioinformatics (DNA alignment), and plagiarism detection.

DP Formulation
STATEdp[i][j] = length of LCS of X[0..i−1] and Y[0..j−1].
MATCHIf X[i−1] == Y[j−1]: dp[i][j] = dp[i−1][j−1] + 1. Characters match — extend the LCS by one.
SKIPElse: dp[i][j] = max(dp[i−1][j], dp[i][j−1]). Take the best by skipping one character from either string.
ANSWERdp[m][n] gives the LCS length. Traceback reconstructs the actual subsequence.
C++ 17LCS — With Traceback
std::string lcs(const std::string& X, const std::string& Y) {
    int m = X.size(), n = Y.size();
    std::vector<std::vector<int>> dp(m+1, std::vector<int>(n+1, 0));

    // Fill DP table
    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            dp[i][j] = (X[i-1] == Y[j-1])
                       ? dp[i-1][j-1] + 1
                       : std::max(dp[i-1][j], dp[i][j-1]);

    // Traceback to reconstruct LCS string
    std::string result;
    int i = m, j = n;
    while (i > 0 && j > 0) {
        if (X[i-1] == Y[j-1]) { result += X[i-1]; i--; j--; }
        else if (dp[i-1][j] > dp[i][j-1]) i--;
        else j--;
    }
    std::reverse(result.begin(), result.end());
    return result;
}
// Time: O(m·n) | Space: O(m·n)

5.4 Edit Distance (Levenshtein Distance)

Edit Distance is the minimum number of single-character operations (insert, delete, replace) to transform one string into another. It powers spell checkers, DNA alignment, and fuzzy string matching.

DP Formulation
STATEdp[i][j] = minimum operations to convert X[0..i−1] to Y[0..j−1].
BASEdp[i][0] = i (delete all i chars). dp[0][j] = j (insert all j chars).
MATCHIf X[i−1] == Y[j−1]: dp[i][j] = dp[i−1][j−1]. No operation needed.
ELSEdp[i][j] = 1 + min(dp[i−1][j], dp[i][j−1], dp[i−1][j−1]) for delete, insert, replace respectively.
C++ 17Levenshtein Edit Distance
int editDistance(const std::string& X, const std::string& Y) {
    int m = X.size(), n = Y.size();
    std::vector<std::vector<int>> dp(m+1, std::vector<int>(n+1));

    for (int i = 0; i <= m; i++) dp[i][0] = i;
    for (int j = 0; j <= n; j++) dp[0][j] = j;

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (X[i-1] == Y[j-1])
                dp[i][j] = dp[i-1][j-1]; // No operation
            else
                dp[i][j] = 1 + std::min({dp[i-1][j],    // Delete
                                          dp[i][j-1],    // Insert
                                          dp[i-1][j-1]}); // Replace
        }
    }
    return dp[m][n];
}
// editDistance("kitten", "sitting") = 3
// Time: O(m·n) | Space: O(m·n)

Greedy Algorithms & Backtracking

Greedy algorithms make the locally optimal choice at each step, while backtracking systematically explores all candidates. Together they solve problems where DP would be over-engineering or impossible.

6.1 Activity Selection Problem

Given n activities with start and finish times, select the maximum number of non-overlapping activities. The greedy insight: always pick the activity that finishes earliest—this leaves the most room for future activities.

Algorithm Steps
01Sort all activities by finish time (ascending).
02Select the first activity. Set lastFinish = finish time of first activity.
03For each subsequent activity: if its start time ≥ lastFinish, select it and update lastFinish.
04Continue through all activities. The selected set is the maximum non-overlapping schedule.
C++ 17Activity Selection — Greedy
struct Activity { int start, finish; };

std::vector<Activity> activitySelection(std::vector<Activity> acts) {
    // Sort by finish time (greedy choice property)
    std::sort(acts.begin(), acts.end(),
              [](const Activity& a, const Activity& b) {
                  return a.finish < b.finish;
              });

    std::vector<Activity> selected = {acts[0]};
    int lastFinish = acts[0].finish;

    for (int i = 1; i < acts.size(); i++)
        if (acts[i].start >= lastFinish) {
            selected.push_back(acts[i]);
            lastFinish = acts[i].finish;
        }
    return selected;
}
// Time: O(n log n) for sort + O(n) scan | Space: O(n)

6.2 Huffman Coding

Huffman coding builds an optimal prefix-free binary code for a set of symbols based on their frequencies. More frequent symbols get shorter codes. It achieves the minimum total bits for lossless compression—used in ZIP, JPEG, MP3, and HTTP/2.

Algorithm Steps
01Create a leaf node for each symbol and add to a min-priority queue ordered by frequency.
02While the queue has more than one node: extract the two nodes with minimum frequency.
03Create a new internal node with frequency = sum of the two extracted. Set them as left and right children.
04Insert the new node back into the priority queue.
05The remaining node is the root of the Huffman tree. Assign codes by traversal: left branch = '0', right branch = '1'.
C++ 17Huffman Coding Tree
struct HuffNode {
    char ch; int freq;
    HuffNode* left; HuffNode* right;
    HuffNode(char c, int f) : ch(c), freq(f), left(nullptr), right(nullptr) {}
    HuffNode(int f, HuffNode* l, HuffNode* r) : ch('\0'), freq(f), left(l), right(r) {}
};

struct Compare {
    bool operator()(HuffNode* a, HuffNode* b) { return a->freq > b->freq; }
};

HuffNode* buildHuffman(const std::unordered_map<char,int>& freq) {
    std::priority_queue<HuffNode*, std::vector<HuffNode*>, Compare> pq;
    for (auto& [ch, f] : freq) pq.push(new HuffNode(ch, f));

    while (pq.size() > 1) {
        auto* l = pq.top(); pq.pop();
        auto* r = pq.top(); pq.pop();
        pq.push(new HuffNode(l->freq + r->freq, l, r));
    }
    return pq.top();
}

void getCodes(HuffNode* root, std::string code,
              std::unordered_map<char,std::string>& codes) {
    if (!root) return;
    if (!root->left && !root->right) { codes[root->ch] = code; return; }
    getCodes(root->left,  code + "0", codes);
    getCodes(root->right, code + "1", codes);
}
// Time: O(n log n) | Space: O(n)

6.3 N-Queens — Backtracking

Place N queens on an N×N chessboard so that no two queens attack each other (no shared row, column, or diagonal). This is the canonical backtracking problem: build a solution incrementally, abandoning ("backtrack") as soon as a placement is invalid.

Algorithm Steps
01Place queens row by row, starting at row 0.
02For each column in the current row: check if placing a queen here is safe (no conflict with any previously placed queen).
03A placement at (row, col) is safe if no queen exists in: the same column, the diagonal (row−col == constant), or the anti-diagonal (row+col == constant).
04If safe, place the queen and recurse to the next row.
05If recursion returns (failed), remove the queen (backtrack) and try the next column.
06If all N queens are placed (row == N), record the solution.

C++ 17N-Queens — Backtracking with Bitmask Optimization
class NQueens {
    int N, solutions = 0;
    std::vector<int> board;
    std::set<int> cols, diag1, diag2; // Attack sets

public:
    NQueens(int n) : N(n), board(n, -1) {}

    void solve(int row = 0) {
        if (row == N) { solutions++; return; }
        for (int col = 0; col < N; col++) {
            if (cols.count(col) || diag1.count(row - col) ||
                diag2.count(row + col)) continue;

            // Place queen
            board[row] = col;
            cols.insert(col); diag1.insert(row-col); diag2.insert(row+col);

            solve(row + 1);

            // Backtrack: remove queen
            cols.erase(col); diag1.erase(row-col); diag2.erase(row+col);
        }
    }

    int getSolutions() const { return solutions; }
};
// NQueens(8).solve() → 92 solutions
// Time: O(N!) worst case | Space: O(N)

1. Understand the problem constraints (n, time limit, memory limit) before choosing an algorithm.
2. Prove correctness before optimizing. A fast wrong answer is useless.
3. Prefer the simplest algorithm that meets your constraints. Don't over-engineer.
