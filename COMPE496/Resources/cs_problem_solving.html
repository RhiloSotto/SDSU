Problem 1: Two Sum

Problem Statement: Given an array of integers nums and an integer target, return the indices of the two numbers such that they add up to target. You may assume that each input has exactly one solution, and you may not use the same element twice.

Time: O(n) Space: O(n)

Solution Methodology

The brute-force approach checks every pair in O(n²), but we can do much better using a hash map. The key insight is: for each element nums[i], we need to find whether target - nums[i] already exists in the array. A hash map gives us O(1) average lookup time.

Algorithm Steps:

  1. Create an empty hash map that maps value → index.
  2. Iterate through the array. For each element nums[i], compute complement = target - nums[i].
  3. Check if complement exists in the hash map. If yes, return [map[complement], i].
  4. Otherwise, insert nums[i] → i into the hash map and continue.

This single-pass approach is elegant because we build the map as we go, ensuring we never use the same element twice.

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

/* Simple hash map using open addressing for Two Sum.
   In production, use a proper hash table library. */
#define TABLE_SIZE 1024

typedef struct {
    int key;       // the value from nums[]
    int value;     // the index in nums[]
    int occupied;  // 0 = empty, 1 = used
} Entry;

int hash(int key) {
    unsigned int k = (unsigned int)key;
    return (k % TABLE_SIZE + TABLE_SIZE) % TABLE_SIZE;
}

int* twoSum(int* nums, int numsSize, int target, int* returnSize) {
    Entry table[TABLE_SIZE];
    memset(table, 0, sizeof(table));

    int* result = malloc(2 * sizeof(int));
    *returnSize = 2;

    for (int i = 0; i < numsSize; i++) {
        int complement = target - nums[i];
        int h = hash(complement);

        // Linear probing to find complement
        while (table[h].occupied) {
            if (table[h].key == complement) {
                result[0] = table[h].value;
                result[1] = i;
                return result;
            }
            h = (h + 1) % TABLE_SIZE;
        }

        // Insert current element
        h = hash(nums[i]);
        while (table[h].occupied) h = (h + 1) % TABLE_SIZE;
        table[h] = (Entry){ .key = nums[i], .value = i, .occupied = 1 };
    }

    *returnSize = 0;
    return result;
}

Problem 2: Maximum Subarray (Kadane's Algorithm)

Problem Statement: Given an integer array nums, find the contiguous subarray (containing at least one number) which has the largest sum and return its sum. For example, given [-2,1,-3,4,-1,2,1,-5,4], the answer is 6 (subarray [4,-1,2,1]).

Time: O(n) Space: O(1)

Solution Methodology

Kadane's algorithm is a textbook example of dynamic programming reduced to its simplest form. We define dp[i] as the maximum sum of a subarray ending at index i. The recurrence is:

dp[i] = max(nums[i], dp[i-1] + nums[i])

At each position, we make a binary decision: either extend the previous subarray by including nums[i], or start a fresh subarray from nums[i]. Since dp[i] only depends on dp[i-1], we only need a single variable current_max instead of a full array.

Algorithm Steps:

  1. Initialize current_max = nums[0] and global_max = nums[0].
  2. For each element from index 1 onward: current_max = max(nums[i], current_max + nums[i]).
  3. Update global_max = max(global_max, current_max).
  4. After the loop, global_max holds the answer.

#include <stdio.h>

/* Kadane's Algorithm — O(n) time, O(1) space */
int maxSubArray(int* nums, int n) {
    int current_max = nums[0];
    int global_max  = nums[0];

    for (int i = 1; i < n; i++) {
        // Extend or restart?
        current_max = (nums[i] > current_max + nums[i])
                    ? nums[i]
                    : current_max + nums[i];

        if (current_max > global_max)
            global_max = current_max;
    }
    return global_max;
}

int main() {
    int nums[] = {-2, 1, -3, 4, -1, 2, 1, -5, 4};
    int n = sizeof(nums) / sizeof(nums[0]);
    printf("Max subarray sum: %d\n", maxSubArray(nums, n));
    return 0;
}

Problem 3: Dutch National Flag (Sort Colors)

Problem Statement: Given an array nums with n objects colored red (0), white (1), or blue (2), sort them in-place so that objects of the same color are adjacent, in the order 0, 1, 2. You must solve this without using the library sort function, in a single pass with O(1) extra space.

Time: O(n) Space: O(1)

Solution Methodology

This problem, originally formulated by Edsger Dijkstra, is solved with a three-way partitioning scheme using three pointers: low, mid, and high. The invariant maintained throughout the algorithm is:

  • Everything in [0, low) is 0 (red).
  • Everything in [low, mid) is 1 (white).
  • Everything in (high, n-1] is 2 (blue).
  • Everything in [mid, high] is unclassified.

Algorithm Steps:

  1. Initialize low = 0, mid = 0, high = n - 1.
  2. While mid ≤ high:
    • If nums[mid] == 0: swap nums[low] and nums[mid], increment both low and mid.
    • If nums[mid] == 1: just increment mid.
    • If nums[mid] == 2: swap nums[mid] and nums[high], decrement high (do not increment mid because the swapped element is unexamined).

Step 0 
#include <stdio.h>

#define SWAP(a, b) do { typeof(a) _t=(a); (a)=(b); (b)=_t; } while(0)

void sortColors(int* nums, int n) {
    int lo = 0, mid = 0, hi = n - 1;

    while (mid <= hi) {
        switch (nums[mid]) {
            case 0: SWAP(nums[lo], nums[mid]); lo++; mid++; break;
            case 1: mid++; break;
            case 2: SWAP(nums[mid], nums[hi]); hi--; break;
        }
    }
}

    int a[] = {2,0,2,1,1,0,1,2,0};
    int n = sizeof(a)/sizeof(a[0]);
    sortColors(a, n);
    for (int i = 0; i < n; i++) printf("%d ", a[i]);
    return 0;
}

Problem 4: Reverse a Linked List

Problem Statement: Given the head of a singly linked list, reverse the list and return the reversed list. You must do this iteratively in O(n) time and O(1) space.

Time: O(n) Space: O(1)

Solution Methodology

We maintain three pointers: prev (initially NULL), curr (initially head), and next (a temporary holder). At each step, we save curr->next, reverse the link by pointing curr->next to prev, then advance both prev and curr one step forward. When curr becomes NULL, prev is the new head.

    int val;
    struct ListNode* next;
};

struct ListNode* reverseList(struct ListNode* head) {
    struct ListNode* prev = NULL;
    struct ListNode* curr = head;

    while (curr != NULL) {
        struct ListNode* next_temp = curr->next;  // save next
        curr->next = prev;                        // reverse link
        prev = curr;                               // advance prev
        curr = next_temp;                          // advance curr
    }
    return prev;  // new head
}

Problem 5: Linked List Cycle Detection (Floyd's Algorithm)

Problem Statement: Given the head of a linked list, determine if the linked list has a cycle. A cycle exists if some node's next pointer points back to a previously visited node. Solve in O(n) time and O(1) space.

Time: O(n) Space: O(1)

Solution Methodology

The Tortoise and Hare algorithm uses two pointers moving at different speeds. The slow pointer (tortoise) moves one node at a time, while the fast pointer (hare) moves two nodes at a time. If there is a cycle, the hare will eventually lap the tortoise and they will meet. If the hare reaches NULL, there is no cycle.

Why it works: Once both pointers are inside the cycle, the distance between them decreases by 1 at each step (since the fast pointer gains 1 node per step). Therefore, they must eventually collide.

#include <stdbool.h>
#include <stddef.h>

bool hasCycle(struct ListNode* head) {
    struct ListNode* slow = head;
    struct ListNode* fast = head;

    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;           // 1 step
        fast = fast->next->next;     // 2 steps

        if (slow == fast)
            return true;          // cycle detected!
    }
    return false;                    // no cycle
}

Problem 6: Valid Parentheses (Stack)

Problem Statement: Given a string s containing just the characters '(', ')', '{', '}', '[', and ']', determine if the input string is valid. A string is valid if: (1) every open bracket is closed by the same type of bracket, (2) open brackets are closed in the correct order, and (3) every close bracket has a corresponding open bracket.

Time: O(n) Space: O(n)

Solution Methodology

This is the quintessential stack problem. We iterate through each character. If it is an opening bracket, we push it onto the stack. If it is a closing bracket, we check whether the top of the stack is the matching opening bracket. If it matches, we pop; otherwise, the string is invalid. At the end, the stack must be empty for the string to be valid.

Valid Parentheses — Interactive Visualization

Press Step or Play to begin.
Step 0 
#include <stdbool.h>
#include <string.h>

bool isValid(char* s) {
    int n = strlen(s);
    char stack[n];   // VLA — valid in C11
    int top = -1;

    for (int i = 0; s[i]; i++) {
        switch (s[i]) {
            case '(': case '[': case '{':
                stack[++top] = s[i];
                break;
            case ')':
                if (top < 0 || stack[top--] != '(') return false;
                break;
            case ']':
                if (top < 0 || stack[top--] != '[') return false;
                break;
            case '}':
                if (top < 0 || stack[top--] != '{') return false;
                break;
        }
    }
    return top == -1;  // stack must be empty
}

Problem 7: Binary Tree Traversals (Inorder, Preorder, Postorder)

Problem Statement: Given the root of a binary tree, return the inorder, preorder, and postorder traversal of its nodes' values. Understand the recursive structure and be able to implement both recursive and iterative versions.

Time: O(n) Space: O(h) where h = tree height

Solution Methodology

Tree traversals are the foundation of almost every tree algorithm. The three classic depth-first traversals differ only in when the current node is processed relative to its children:

  • Preorder (Root → Left → Right): Process the node first, then recurse on left and right subtrees. Used for copying/serializing a tree.
  • Inorder (Left → Root → Right): Recurse left, process node, recurse right. For a BST, this yields sorted order.
  • Postorder (Left → Right → Root): Recurse on both children first, then process the node. Used for deletion and expression evaluation.

#include <stdio.h>
#include <stdlib.h>

struct TreeNode {
    int val;
    struct TreeNode* left;
    struct TreeNode* right;
};

/* ---- Recursive Traversals ---- */
void inorder(struct TreeNode* root, int* res, int* idx) {
    if (!root) return;
    inorder(root->left, res, idx);
    res[(*idx)++] = root->val;          // process node
    inorder(root->right, res, idx);
}

void preorder(struct TreeNode* root, int* res, int* idx) {
    if (!root) return;
    res[(*idx)++] = root->val;          // process node FIRST
    preorder(root->left, res, idx);
    preorder(root->right, res, idx);
}

void postorder(struct TreeNode* root, int* res, int* idx) {
    if (!root) return;
    postorder(root->left, res, idx);
    postorder(root->right, res, idx);
    res[(*idx)++] = root->val;          // process node LAST
}

/* ---- Iterative Inorder using explicit stack ---- */
int* inorderIterative(struct TreeNode* root, int* returnSize) {
    int* res = malloc(1000 * sizeof(int));
    struct TreeNode* stack[1000];
    int top = -1, idx = 0;
    struct TreeNode* curr = root;

    while (curr || top >= 0) {
        while (curr) {                  // go left as far as possible
            stack[++top] = curr;
            curr = curr->left;
        }
        curr = stack[top--];            // pop
        res[idx++] = curr->val;         // process
        curr = curr->right;             // go right
    }
    *returnSize = idx;
    return res;
}

Problem 8: Lowest Common Ancestor of a BST

Problem Statement: Given a Binary Search Tree (BST) and two nodes p and q, find their Lowest Common Ancestor (LCA). The LCA is the deepest node that is an ancestor of both p and q.

Time: O(h) Space: O(1) iterative

Solution Methodology

In a BST, the key property is that for any node, all values in the left subtree are smaller and all values in the right subtree are larger. The LCA of p and q is the first node where p and q "split" — one goes left and the other goes right (or one of them equals the current node).

Algorithm Steps:

  1. Start at the root.
  2. If both p and q are smaller than the current node, move left.
  3. If both p and q are larger than the current node, move right.
  4. Otherwise, the current node is the LCA (the "split point").

        } else if (p->val > root->val && q->val > root->val) {
            root = root->right;         // both in right subtree
        } else {
            return root;                // split point = LCA
        }
    }
    return NULL;
}

Problem 9: Validate Binary Search Tree

Problem Statement: Given the root of a binary tree, determine if it is a valid Binary Search Tree. A valid BST is defined as: the left subtree of a node contains only nodes with keys strictly less than the node's key, and the right subtree contains only nodes with keys strictly greater than the node's key. Both subtrees must also be valid BSTs.

Time: O(n) Space: O(h)

Solution Methodology

A common mistake is to only check that left->val < root->val < right->val locally. This misses cases where a node deep in the left subtree violates the constraint of an ancestor. The correct approach is to pass down a valid range (min, max) for each node.

Algorithm Steps:

  1. Start with the range (-∞, +∞).
  2. For the left child, narrow the range to (min, root->val).
  3. For the right child, narrow the range to (root->val, max).
  4. If any node's value falls outside its allowed range, return false.
#include <stdbool.h>
#include <limits.h>

bool validate(struct TreeNode* node, long min_val, long max_val) {
    if (!node) return true;

    if (node->val <= min_val || node->val >= max_val)
        return false;

    return validate(node->left,  min_val, node->val)
        && validate(node->right, node->val, max_val);
}

bool isValidBST(struct TreeNode* root) {
    return validate(root, LONG_MIN, LONG_MAX);
}
C11
Pro Tip: An alternative approach is to perform an inorder traversal and check that the resulting sequence is strictly increasing. This is often easier to implement and debug.

Problem 10: Merge Sort

Problem Statement: Implement Merge Sort to sort an array of integers. Merge Sort is a divide-and-conquer algorithm that divides the array into halves, recursively sorts each half, and then merges the two sorted halves. It guarantees O(n log n) time in all cases.

Time: O(n log n) Space: O(n)

Solution Methodology

Merge Sort works in two phases:

  1. Divide: Split the array into two halves at the midpoint. Recursively sort each half until you reach subarrays of size 1 (which are trivially sorted).
  2. Conquer (Merge): Merge two sorted halves into a single sorted array. Use two pointers, one for each half. Compare the elements they point to, take the smaller one, and advance that pointer. Continue until both halves are exhausted.

The merge step is the heart of the algorithm. It takes O(n) time and O(n) space for the temporary buffer. The recursion depth is O(log n), giving us O(n log n) total.

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

void merge(int* arr, int l, int m, int r) {
    int n1 = m - l + 1;
    int n2 = r - m;

    // VLA temporaries (C11)
    int L[n1], R[n2];
    memcpy(L, arr + l,     n1 * sizeof(int));
    memcpy(R, arr + m + 1, n2 * sizeof(int));

    int i = 0, j = 0, k = l;
    while (i < n1 && j < n2)
        arr[k++] = (L[i] <= R[j]) ? L[i++] : R[j++];
    while (i < n1) arr[k++] = L[i++];
    while (j < n2) arr[k++] = R[j++];
}

void mergeSort(int* arr, int l, int r) {
    if (l < r) {
        int m = l + (r - l) / 2;   // overflow-safe midpoint
        mergeSort(arr, l, m);
        mergeSort(arr, m + 1, r);
        merge(arr, l, m, r);
    }
}

Problem 11: Quick Sort (Lomuto Partition)

Problem Statement: Implement Quick Sort using the Lomuto partition scheme. Quick Sort is another divide-and-conquer sorting algorithm that works by selecting a "pivot" element and partitioning the array around it. It has O(n log n) average-case time but O(n²) worst-case.

Time: O(n log n) average Space: O(log n) stack

Solution Methodology

The Lomuto partition scheme is simpler to understand than Hoare's. It works as follows:

  1. Choose the last element as the pivot.
  2. Maintain a pointer i that tracks the boundary of elements ≤ pivot.
  3. Scan from left to right with pointer j. Whenever arr[j] ≤ pivot, swap arr[j] with arr[i] and increment i.
  4. After the scan, swap the pivot into position i. Now everything left of i is ≤ pivot, and everything right is > pivot.
  5. Recursively sort the two partitions.

Press Step or Play to begin.
Step 0 
#include <stdio.h>

#define SWAP(a, b) do { typeof(a) _t=(a); (a)=(b); (b)=_t; } while(0)

int partition(int* arr, int lo, int hi) {
    int pivot = arr[hi];   // Lomuto: pivot is last element
    int i = lo - 1;

    for (int j = lo; j < hi; j++) {
        if (arr[j] <= pivot) {
            i++;
            SWAP(arr[i], arr[j]);
        }
    }
    SWAP(arr[i + 1], arr[hi]);
    return i + 1;
}

void quickSort(int* arr, int lo, int hi) {
    if (lo < hi) {
        int pi = partition(arr, lo, hi);
        quickSort(arr, lo, pi - 1);
        quickSort(arr, pi + 1, hi);
    }
}

Problem 12: Binary Search Variants

Problem Statement: Given a sorted array of integers and a target value, implement binary search to find the target. Then extend it to find the first occurrence (lower bound) and last occurrence (upper bound) of the target.

Time: O(log n) Space: O(1)

Solution Methodology

Binary search repeatedly halves the search space. The key is maintaining the invariant: the answer is always within [lo, hi]. For the standard version, if arr[mid] == target, we return. For lower/upper bound variants, we continue searching even after finding a match to find the boundary.

Lower Bound: When arr[mid] >= target, set hi = mid. When arr[mid] < target, set lo = mid + 1. Result: first index where arr[index] >= target.

Upper Bound: When arr[mid] <= target, set lo = mid + 1. When arr[mid] > target, set hi = mid. Result: first index where arr[index] > target.

#include <stdio.h>

/* Standard binary search */
int binarySearch(int* arr, int n, int target) {
    int lo = 0, hi = n - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;  // overflow-safe
        if      (arr[mid] == target) return mid;
        else if (arr[mid] <  target) lo = mid + 1;
        else                         hi = mid - 1;
    }
    return -1;
}

/* Lower bound: first index where arr[i] >= target */
int lowerBound(int* arr, int n, int target) {
    int lo = 0, hi = n;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (arr[mid] >= target) hi = mid;
        else                    lo = mid + 1;
    }
    return lo;
}

/* Upper bound: first index where arr[i] > target */
int upperBound(int* arr, int n, int target) {
    int lo = 0, hi = n;
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (arr[mid] > target) hi = mid;
        else                   lo = mid + 1;
    }
    return lo;
}
C11
Pro Tip — Avoiding Off-by-One Errors: The most common bug in binary search is the loop condition and how lo/hi are updated. A useful mental model: think of [lo, hi] as the "candidate range." When the range becomes empty, the search is done. For the standard search, use lo <= hi. For lower/upper bound, use lo < hi with half-open intervals.

Trick 10 — Adjacency List with Dynamic Arrays: For sparse graphs, adjacency lists are far more memory-efficient than matrices. In C11, combine realloc with a growth factor for a simple dynamic array. 
#define MAX_NODES 1000

typedef struct {
    int* neighbors;
    int* weights;    // for weighted graphs
    int size;
    int capacity;
} AdjList;

AdjList graph[MAX_NODES];

void addEdge(int u, int v, int w) {
    AdjList* list = &graph[u];
    if (list->size == list->capacity) {
        list->capacity = list->capacity ? list->capacity * 2 : 4;
        list->neighbors = realloc(list->neighbors, list->capacity * sizeof(int));
        list->weights   = realloc(list->weights,   list->capacity * sizeof(int));
    }
    list->neighbors[list->size] = v;
    list->weights[list->size]   = w;
    list->size++;
}

Problem 13: BFS Shortest Path (Unweighted Graph)

Problem Statement: Given an unweighted graph with V vertices and E edges, find the shortest path (minimum number of edges) from a source vertex s to all other vertices using Breadth-First Search.

Time: O(V + E) Space: O(V)

Solution Methodology

BFS explores the graph level by level, like ripples spreading from a stone dropped in water. It uses a queue (FIFO) to process vertices in the order they are discovered. Because it explores all vertices at distance d before any vertex at distance d+1, the first time a vertex is reached, it is via the shortest path.

Algorithm Steps:

  1. Initialize a distance array with all values set to -1 (unvisited). Set dist[source] = 0.
  2. Enqueue the source vertex.
  3. While the queue is not empty: dequeue a vertex u, and for each neighbor v of u, if v is unvisited, set dist[v] = dist[u] + 1 and enqueue v.

Step 0 
#include <stdio.h>
#include <string.h>

#define MAXV 1000

int adj[MAXV][MAXV], deg[MAXV];  // adjacency list
int dist[MAXV], parent[MAXV];
int queue[MAXV], front, back;

void bfs(int src, int V) {
    memset(dist, -1, V * sizeof(int));
    memset(parent, -1, V * sizeof(int));
    front = back = 0;

    dist[src] = 0;
    queue[back++] = src;

    while (front < back) {
        int u = queue[front++];
        for (int i = 0; i < deg[u]; i++) {
            int v = adj[u][i];
            if (dist[v] == -1) {       // unvisited
                dist[v] = dist[u] + 1;
                parent[v] = u;
                queue[back++] = v;
            }
        }
    }
}

Problem 14: DFS & Topological Sort

Problem Statement: Given a Directed Acyclic Graph (DAG) with V vertices and E edges, find a topological ordering of the vertices. A topological sort is a linear ordering of vertices such that for every directed edge u → v, vertex u comes before v.

Time: O(V + E) Space: O(V)

Solution Methodology

Topological sort can be implemented using DFS. The key insight is: when DFS finishes processing a vertex (all its descendants have been visited), that vertex can be placed at the front of the topological order. We use a stack (or simply reverse the finish order).

Algorithm Steps:

  1. Mark all vertices as unvisited.
  2. For each unvisited vertex, run DFS.
  3. In DFS, after visiting all neighbors of a vertex, push it onto a stack.
  4. The stack (read top to bottom) gives the topological order.

Topological Sort (DFS) — Interactive Visualization

Press Step or Play to begin.
Step 0 
#include <stdio.h>
#include <stdbool.h>

#define MAXV 1000

int adj[MAXV][MAXV], deg[MAXV];
bool visited[MAXV];
int stack[MAXV], stack_top;

void dfs(int u) {
    visited[u] = true;
    for (int i = 0; i < deg[u]; i++) {
        int v = adj[u][i];
        if (!visited[v])
            dfs(v);
    }
    stack[stack_top++] = u;  // push after all descendants done
}

void topologicalSort(int V) {
    for (int i = 0; i < V; i++) visited[i] = false;
    stack_top = 0;

    for (int i = 0; i < V; i++)
        if (!visited[i]) dfs(i);

    // Print in reverse stack order
    printf("Topological Order: ");
    for (int i = stack_top - 1; i >= 0; i--)
        printf("%d ", stack[i]);
    printf("\n");
}

Problem 15: Dijkstra's Shortest Path Algorithm

Problem Statement: Given a weighted graph with non-negative edge weights, find the shortest path from a source vertex to all other vertices using Dijkstra's algorithm.

Time: O((V + E) log V) with min-heap Space: O(V)

Solution Methodology

Dijkstra's algorithm is a greedy algorithm that builds the shortest path tree one vertex at a time. It maintains a set of "finalized" vertices and a priority queue of tentative distances. At each step, it extracts the vertex with the smallest tentative distance, finalizes it, and relaxes all its outgoing edges.

Relaxation: For an edge (u, v) with weight w, if dist[u] + w < dist[v], update dist[v] = dist[u] + w.

Algorithm Steps:

  1. Initialize dist[source] = 0, all others to ∞. Insert source into the priority queue.
  2. Extract the vertex u with minimum distance from the priority queue.
  3. For each neighbor v of u: if dist[u] + weight(u,v) < dist[v], update dist[v] and insert/update v in the priority queue.
  4. Repeat until the priority queue is empty.

Step 0 
/* Dijkstra's Algorithm — C++ with priority_queue */
#include <bits/stdc++.h>
using namespace std;

typedef pair<int,int> pii;  // {distance, node}

vector<int> dijkstra(int src, vector<vector<pii>>& adj, int V) {
    vector<int> dist(V, INT_MAX);
    priority_queue<pii, vector<pii>, greater<pii>> pq;

    dist[src] = 0;
    pq.push({0, src});

    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();

        if (d > dist[u]) continue;  // stale entry

        for (auto& [v, w] : adj[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
    return dist;
}

Pro Tip — When NOT to use Dijkstra: Dijkstra's algorithm fails with negative edge weights. For graphs with negative weights (but no negative cycles), use the Bellman-Ford algorithm. For all-pairs shortest paths, consider Floyd-Warshall.

Problem 16: Fibonacci — Memoization vs. Tabulation

Problem Statement: Compute the n-th Fibonacci number efficiently. The naive recursive solution has exponential time complexity O(2n). Demonstrate both top-down (memoization) and bottom-up (tabulation) approaches to achieve O(n) time.

Time: O(n) Space: O(n) or O(1)

Solution Methodology

The Fibonacci sequence is the "Hello World" of dynamic programming. The naive recursive approach recomputes the same subproblems exponentially many times. DP eliminates this redundancy.

Top-Down (Memoization): Keep the recursive structure but cache results in an array. Before computing fib(n), check if it's already in the cache. This is "lazy" — we only compute what's needed.

Bottom-Up (Tabulation): Fill a table iteratively from fib(0) up to fib(n). No recursion overhead. Can be further optimized to O(1) space since we only need the last two values.

Step 0 
#include <stdio.h>
#include <string.h>

/* ---- Top-Down: Memoization ---- */
long long memo[100];

long long fib_memo(int n) {
    if (n <= 1) return n;
    if (memo[n] != -1) return memo[n];
    return memo[n] = fib_memo(n - 1) + fib_memo(n - 2);
}

/* ---- Bottom-Up: Tabulation ---- */
long long fib_tab(int n) {
    if (n <= 1) return n;
    long long dp[n + 1];  // VLA
    dp[0] = 0; dp[1] = 1;
    for (int i = 2; i <= n; i++)
        dp[i] = dp[i-1] + dp[i-2];
    return dp[n];
}

/* ---- Space-Optimized O(1) ---- */
long long fib_opt(int n) {
    if (n <= 1) return n;
    long long a = 0, b = 1;
    for (int i = 2; i <= n; i++) {
        long long c = a + b;
        a = b; b = c;
    }
    return b;
}

Problem 17: 0/1 Knapsack Problem

Problem Statement: Given n items, each with a weight w[i] and a value v[i], and a knapsack with capacity W, determine the maximum total value you can carry. Each item can either be taken or left (0/1 choice — no fractions).

Time: O(nW) Space: O(nW) or O(W)

Solution Methodology

The 0/1 Knapsack is the canonical DP problem. We define dp[i][w] as the maximum value achievable using the first i items with capacity w. The recurrence is:

dp[i][w] = max(dp[i-1][w], dp[i-1][w - weight[i]] + value[i]) if weight[i] ≤ w

The first option means we skip item i. The second means we take it (subtracting its weight and adding its value). We fill the table row by row.

Press Step or Play to begin.
Step 0 
#include <stdio.h>
#include <string.h>

#define MAX(a,b) ((a)>(b)?(a):(b))

int knapsack(int n, int W, int wt[], int val[]) {
    int dp[n + 1][W + 1];  // VLA
    memset(dp, 0, sizeof(dp));

    for (int i = 1; i <= n; i++) {
        for (int w = 0; w <= W; w++) {
            dp[i][w] = dp[i-1][w];  // skip item i
            if (wt[i-1] <= w) {
                dp[i][w] = MAX(dp[i][w],
                    dp[i-1][w - wt[i-1]] + val[i-1]);
            }
        }
    }
    return dp[n][W];
}

/* Space-optimized 1D version */
int knapsack_opt(int n, int W, int wt[], int val[]) {
    int dp[W + 1];
    memset(dp, 0, sizeof(dp));

    for (int i = 0; i < n; i++)
        for (int w = W; w >= wt[i]; w--)  // reverse to avoid reuse
            dp[w] = MAX(dp[w], dp[w - wt[i]] + val[i]);

    return dp[W];
}

Problem 18: Longest Common Subsequence (LCS)

Problem Statement: Given two strings text1 and text2, return the length of their longest common subsequence. A subsequence is a sequence that can be derived from another sequence by deleting some or no elements without changing the order of the remaining elements.

Time: O(mn) Space: O(mn)

Solution Methodology

We define dp[i][j] as the length of the LCS of text1[0..i-1] and text2[0..j-1]. The recurrence is:

  • If text1[i-1] == text2[j-1]: dp[i][j] = dp[i-1][j-1] + 1 (characters match, extend LCS).
  • Otherwise: dp[i][j] = max(dp[i-1][j], dp[i][j-1]) (skip one character from either string).

To reconstruct the actual LCS string, backtrack from dp[m][n]: if the characters match, include it and move diagonally; otherwise, move in the direction of the larger value.

Step 0 
#include <stdio.h>
#include <string.h>

#define MAX(a,b) ((a)>(b)?(a):(b))

int longestCommonSubsequence(char* s1, char* s2) {
    int m = strlen(s1);
    int n = strlen(s2);
    int dp[m + 1][n + 1];  // VLA
    memset(dp, 0, sizeof(dp));

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (s1[i-1] == s2[j-1])
                dp[i][j] = dp[i-1][j-1] + 1;
            else
                dp[i][j] = MAX(dp[i-1][j], dp[i][j-1]);
        }
    }
    return dp[m][n];
}

/* Reconstruct the LCS string */
void printLCS(char* s1, char* s2, int m, int n, int dp[][n+1]) {
    char lcs[m + n + 1];
    int idx = dp[m][n] - 1;
    lcs[idx + 1] = '\0';

    int i = m, j = n;
    while (i > 0 && j > 0) {
        if (s1[i-1] == s2[j-1]) {
            lcs[idx--] = s1[i-1];
            i--; j--;
        } else if (dp[i-1][j] > dp[i][j-1]) {
            i--;
        } else {
            j--;
        }
    }
    printf("LCS: %s\n", lcs);
}
C11
Summary — The DP Recipe: (1) Define the state — what does dp[i][j] represent? (2) Write the recurrence — how does the current state relate to smaller subproblems? (3) Identify the base cases. (4) Determine the iteration order. (5) Optimize space if possible (often from 2D to 1D).
