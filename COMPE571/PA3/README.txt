To run the code, use the command line:
python3 schedule.py [input[NUMBER].txt] [RM or EDF] [EE optional]


Examples to get the outputs included in the report:
- python3 schedule.py input1.txt RM
- python3 schedule.py input1.txt RM EE
- python3 schedule.py input1.txt EDF 
- python3 schedule.py input1.txt EDF EE
- python3 schedule.py input2.txt RM
- python3 schedule.py input2.txt RM EE
- python3 schedule.py input2.txt EDF
- python3 schedule.py input2.txt EDF EE
